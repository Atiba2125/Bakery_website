# Silver Tree Bakery — React website

A multipage React (Vite + React Router) redesign of the Silver Tree Bakery website, using the bakery's own logo, photos and content.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`. The site is a single-page app, so the host must serve `index.html` for every route (a Netlify `_redirects` file is included in `public/`).

## Pages

Home, Locations (+ 3 location pages), Menu, Events (+ event pages), Arbour Club (+ Memberships), Careers, Wholesale enquiries, Community requests, 404.
